## 2. 배경 및 목적

### 2.1 문제 정의

물류 센터를 복수로 운영하는 본사는 각 센터의 운영 현황을 실시간으로 파악하기 어렵다.
센터별 KPI(정시출고율, 미납 현황, 이상 이벤트)가 분산되어 있고, 본사의 지시가 센터에 제때 전달되었는지, 센터가 어떤 조치를 취했는지 추적할 수 있는 통합 창구가 없다.

### 2.2 목적

- 본사가 전국 센터의 물류 성과를 한눈에 모니터링
- 본사 → 센터 간 지시/확인/조치/보고의 **워크플로우**를 단일 시스템으로 관리
- 센터 현장 담당자가 PDA 환경에서도 사용 가능한 간결한 UI 제공

## 4. 기능 요구사항

### 4.1 본사 화면

#### 4.1.1 KPI 요약 카드 (상단 고정)
- 전국 총 재고량
- 평균 정시출고율 (기준 97%)
- 미납 이벤트 건수
- 이상 발생 센터 수

#### 4.1.2 현황 개요 탭
- 센터별 상태 카드: 정상(🟢) / 주의(🟡) / 위험(🔴) 색상 구분
- 센터별 성과 랭킹 테이블 (정시출고율 기준 정렬, 조건부 행 색상)

#### 4.1.3 KPI 추이 탭 (최근 7일)
- 센터별 정시출고율 꺾은선 차트
- 센터별 미납수량 바 차트
- 이상건수 히트맵 테이블 (셀 색상: 0건=녹/1~3건=노/4건+=적)

#### 4.1.4 지시 관리 탭
- 지시 이력 목록: 상태별 아이콘 표시 (📤👀🔧✅)
- 센터 보고 내용 확인 및 승인 버튼
- 대상 센터 선택 후 지시 발송 폼

### 4.2 센터 화면

#### 4.2.1 본사 지시 배너
- 미완료 지시 존재 시 상단에 경고 배너 자동 표시

#### 4.2.2 상태 카드
- 보관 SKU 수 / 출고 진행 건 / 미납 이벤트 / 상태이상 건수

#### 4.2.3 입출고 프로세스 플로우
- 입고 → 보관 → 피킹 → 패킹 → 출고 단계별 처리량 표시
- 병목 단계 강조 표시 (빨간색 + ⚠ 배지)
- 병목 판단 기준:
  - 미입고수량 > 3 → 입고 단계 병목
  - 이상건수 > 0 → 보관 단계 병목
  - 미납수량 > 5 → 출고 단계 병목

#### 4.2.4 일별 입출고 추이
- 최근 7일 입고/출고 그룹 바 차트

#### 4.2.5 이벤트 조치 등록
- 처리 필요 이벤트 리스트 (지연 기준 행 색상 구분)
- 이벤트 선택 → 조치 유형 선택 → 수량 입력 → 등록 폼
- PDA 환경 고려: 드롭다운 + 숫자 스피너 중심

#### 4.2.6 본사 지시 확인 및 결과 보고
- 지시 이력 아코디언 목록
- "👁️ 확인했습니다" 버튼 (상태: 지시완료 → 센터확인중)
- 조치 결과 보고 폼 제출 (상태: → 조치중)

### 7.2 코드값 체계

| 코드 | 자릿수 | 예시 |
|---|---|---|
| CENTER_CODE | 4자리 | C001 |
| VENDOR_CODE | 6자리 | V00001 |
| PRODUCT_CODE | 10자리 | 0000000001 |

## 9. 주요 기술 설계 결정

### 9.1 DB 커넥션 관리
`contextlib.contextmanager`를 사용한 with문 패턴으로 자동 commit / rollback / close 보장

```python
@contextmanager
def get_connection():
    conn = sqlite3.connect(DB_PATH)
    conn.row_factory = sqlite3.Row
    conn.execute("PRAGMA foreign_keys = ON")
    try:
        yield conn
        conn.commit()
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()
```

### 9.2 단일 앱 멀티 뷰
`app.py`의 사이드바 라디오 버튼으로 본사/센터 화면을 전환
→ 별도 서버 없이 단일 프로세스에서 두 역할 모두 지원

### 9.3 PDA 환경 고려
센터 현장 특성상 자유 텍스트 최소화, 드롭다운 + 수량 입력(number_input) 중심 UI

## 11. 향후 개선 검토 사항 (Out of Scope)

| 항목 | 이유 |
|---|---|
| 전국 지도 시각화 (센터 위치 핀) | folium 라이브러리 + 좌표 데이터 필요, 별도 구현 범위 |

| 알림 기능 (이메일/Slack) | 외부 API 연동 필요 |
| 웹 서비스 배포 | 서버 인프라 (AWS / GCP 등) 구축 필요 |

## 12. 실행 방법

```bash
# 1. 패키지 설치
pip install streamlit pandas

# 2. DB 초기화 (최초 1회)
python init_db.py

# 3. 샘플 데이터 삽입 (최초 1회)
python seed_data.py

# 4. 앱 실행
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 접속
